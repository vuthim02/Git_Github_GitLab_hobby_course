## Project Overview

Create a professional portfolio repository that demonstrates your Git mastery. This will be the first thing potential employers see when reviewing your GitHub/GitLab profile.

---

## Project Structure

```
portfolio/
├── README.md                 # Your portfolio landing page
├── projects/                 # Showcase your work
│   ├── project-1/
│   └── project-2/
├── skills/                  # Skills demonstration
├── experience/              # Work history
├── CONTRIBUTING.md          # Contribution guidelines
└── .github/
    ├── ISSUE_TEMPLATE.md    # Issue templates
    └── PULL_REQUEST_TEMPLATE.md  # PR templates
```

---

## Project Checklist

### Phase 1: Repository Setup (Day 1)

- [ ] Create repository on GitHub/GitLab
- [ ] Add professional README.md
- [ ] Create .gitignore file
- [ ] Add license (MIT recommended)
- [ ] Set up GitHub Pages (optional)

### Phase 2: Documentation (Day 2)

- [ ] Create projects folder
- [ ] Document your skills
- [ ] Add work experience
- [ ] Create contribution guidelines
- [ ] Add issue templates

### Phase 3: Git Practice (Day 3)

- [ ] Make meaningful commits with proper messages
- [ ] Create feature branches
- [ ] Practice branching workflow
- [ ] Merge with proper strategy
- [ ] Clean up merged branches

### Phase 4: GitHub/GitLab Features (Day 4)

- [ ] Enable GitHub Pages
- [ ] Add topics/labels
- [ ] Pin repository to profile
- [ ] Create release
- [ ] Set up project board

## Git Commands Practiced

| Command | Purpose |
|---------|---------|
| `git init` | Initialize repository |
| `git add` | Stage changes |
| `git commit` | Commit with message |
| `git branch` | Create feature branches |
| `git merge` | Merge branches |
| `git push` | Push to remote |
| `git pull` | Pull from remote |
| `git log` | View history |
| `git diff` | Compare changes |
