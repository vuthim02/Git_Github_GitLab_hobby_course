# Day 54 Reflections: Custom Aliases

## What I Learned Today

### Key Takeaways

1. **Git Aliases**
   - Shortcuts for long commands
   - `git config --global alias.<name> "<command>"`
   - Can use shell commands with !

2. **Shell Aliases**
   - Terminal shortcuts
   - Added to ~/.bashrc or ~/.zshrc
   - Work in any directory

3. **Useful Aliases**
   - st: status -sb
   - co: checkout
   - lg: log --oneline --graph
   - undo: reset --soft HEAD~1
