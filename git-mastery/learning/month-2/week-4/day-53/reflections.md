# Day 53 Reflections: Worktrees

## What I Learned Today

### Key Takeaways

1. **Git Worktrees**
   - Multiple working directories from one repo
   - Each worktree = one branch
   - Useful for context switching

2. **Commands**
   - Create: `git worktree add <path> <branch>`
   - List: `git worktree list`
   - Remove: `git worktree remove <path>`
