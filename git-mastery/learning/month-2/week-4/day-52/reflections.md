# Day 52 Reflections: Submodules & Subtrees

## What I Learned Today

### Key Takeaways

1. **Submodules**
   - Git repo inside a git repo
   - Separate versioning
   - Useful for dependencies

2. **Commands**
   - Add: `git submodule add <url> <path>`
   - Clone: `git clone --recurse-submodules <url>`
   - Update: `git submodule update --remote`
   - Init: `git submodule init`
