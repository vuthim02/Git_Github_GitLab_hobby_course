# Day 46: Common Mistakes - Code Reviews

## Mistake 1: Not Reviewing Regularly

**Problem:**
- PRs pile up
- Blocked features
- Stale code

**Solution:**
- Review daily
- Set time aside
- Respond within 24 hours

---

## Mistake 2: Being a Code Dictator

**Wrong:**
```
"All variables must be snake_case"
"No, I prefer differently"
"I don't care, follow my rules"
```

**Right:**
- Focus on what matters
- Use linters for style
- Allow team conventions

---

## Lesson Learned

> "Code review is about improving code AND sharing knowledge. Be a teacher, not a dictator."

**Golden Rules:**
1. Review regularly
2. Be kind and constructive
3. Focus on logic, not style
4. Praise good work
5. Ask questions, don't assume
