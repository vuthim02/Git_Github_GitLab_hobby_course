# Day 42: Common Mistakes - Week 6 Review

## Key Mistakes to Avoid

### GitLab CI/CD Mistakes

1. **Not testing locally**
   - Use GitLab Runner locally
   - Test before pushing

2. **Wrong stage order**
   - Deploy must come after test
   - Test must come after build

3. **Missing dependencies**
   - Install dependencies in script
   - Cache dependencies
