# Day 36: Common Mistakes - GitLab Overview

## Mistake 1: Confusing GitLab with GitHub
**Fix:** GitLab is similar but has different features - CI/CD is built-in

## Mistake 2: Wrong Clone URL
**Fix:** Use gitlab.com URL, not github.com

## Mistake 3: No CLI
**Fix:** Install glab for GitLab CLI

## Lesson: GitLab is a complete DevOps platform with built-in CI/CD
