# Day 37 Reflections: GitLab Merge Requests

## What I Learned Today

### Key Takeaways
1. MRs are GitLab's version of PRs
2. Same workflow: branch → push → create MR → review → merge
3. CLI tool: glab for MR management
4. Features similar to GitHub PRs

### Commands Mastered
```bash
glab mr create
glab mr list
glab mr approve
glab mr merge
```
