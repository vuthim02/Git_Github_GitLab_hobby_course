# Day 37: Common Mistakes - GitLab Merge Requests

## Mistake 1: Wrong Target Branch
**Fix:** Select main (or correct target)

## Mistake 2: No Description
**Fix:** Add detailed description with testing notes

## Mistake 3: Not Waiting for Pipeline
**Fix:** Wait for CI/CD pipeline to pass before merging

## Mistake 4: No Review
**Fix:** Get at least one approval before merging

## Mistake 5: Ignoring Comments
**Fix:** Address comments before merging

---

## Lesson: MRs require good description, reviews, and passing checks
