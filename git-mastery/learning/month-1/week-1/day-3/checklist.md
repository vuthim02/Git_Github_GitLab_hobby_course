## 🎯 Knowledge Check

### Can You Answer These?

1. **What command creates a new Git repository?**
   - [ ] git create
   - [ ] git new
   - [ ] git init ✓
   - [ ] git start

2. **Where does Git store all repository data?**
   - [ ] In a hidden file called `.gitdata`
   - [ ] In the `.git` directory ✓
   - [ ] In `.gitconfig`
   - [ ] In `git-repository.txt`

3. **What does `git status` show?**
   - [ ] Only committed changes
   - [ ] Only the current branch
   - [ ] Current branch, staged, modified, and untracked files ✓
   - [ ] The commit history

4. **Is it safe to run `git init` in an existing repository?**
   - [ ] No, it will delete all history
   - [ ] Yes, it won't harm existing data ✓
   - [ ] Only if you use the `--force` flag
   - [ ] No, it will create conflicts

5. **What is the `.git` directory?**
   - [ ] A backup of your files
   - [ ] The working directory
   - [ ] Git's database containing all objects and refs ✓
   - [ ] A log of all commands
