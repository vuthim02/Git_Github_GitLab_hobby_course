## 🎯 Knowledge Check

### Can You Answer These?

1. **What does `git add` do?**
   - [ ] Commits changes to repository
   - [ ] Copies changes to staging area ✓
   - [ ] Creates a new branch
   - [ ] Shows differences

2. **What's the staging area?**
   - [ ] A backup of your files
   - [ ] A preview of your next commit ✓
   - [ ] The .git folder
   - [ ] A remote server

3. **Which command shows commit history?**
   - [ ] git history
   - [ ] git commits
   - [ ] git log ✓
   - [ ] git show

4. **What does `git commit -am` do?**
   - [ ] Adds and commits all files
   - [ ] Adds tracked files and commits ✓
   - [ ] Amends the last commit
   - [ ] Shows all branches

5. **Should you amend pushed commits?**
   - [ ] Yes, it's fine
   - [ ] No, never ✓
   - [ ] Only with --force
   - [ ] Only in emergencies
