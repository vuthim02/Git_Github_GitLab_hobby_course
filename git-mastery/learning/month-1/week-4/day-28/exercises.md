# Day 28 Exercises: Month 1 Final Review

## Challenge 1: Complete Git Workflow

Demonstrate all Month 1 topics in one workflow:
1. Initialize repository
2. Make commits
3. Create and switch branches
4. Merge branches
5. Rebase for cleanup
6. Cherry-pick a commit
7. Stash changes
8. Reset and recover
9. Push to remote

## Challenge 2: Emergency Recovery

Given a corrupted repository scenario:
1. Make several commits
2. Perform "risky" operations
3. Use reflog to recover

Document each recovery step.

## Challenge 3: Teaching Exercise

Explain these to someone (or write it down):
1. How branching works in Git
2. The difference between merge and rebase
3. How to collaborate with remotes
4. When to use reset vs revert

## Challenge 4: Speed Quiz

Complete these operations quickly:
1. Create branch, add commit, merge (under 1 minute)
2. Stash, switch branches, pop (under 30 seconds)
3. Cherry-pick specific commit (under 30 seconds)
4. Recover from hard reset (under 1 minute)
