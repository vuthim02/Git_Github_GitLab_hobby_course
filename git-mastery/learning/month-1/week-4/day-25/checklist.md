# Day 25 Checklist: Stashing Changes

## Stash Commands

- [ ] `git stash` - Stash changes
- [ ] `git stash push -m "message"` - With message
- [ ] `git stash pop` - Apply and delete
- [ ] `git stash apply` - Apply, keep stash
- [ ] `git stash list` - List stashes
- [ ] `git stash show` - Show stash content
- [ ] `git stash drop` - Delete stash
- [ ] `git stash clear` - Delete all
- [ ] `git stash -u` - Include untracked

## Stash Management

- [ ] View stash list
- [ ] Apply specific stash
- [ ] Delete stashes you don't need
- [ ] Keep stash clean

## Use Cases

- [ ] Switch branches with dirty working directory
- [ ] Pull when you have local changes
- [ ] Temporarily shelve work
- [ ] Test something without committing

## Pop vs Apply

| pop | apply |
|-----|-------|
| Apply and delete | Apply and keep |
| Use most recent | Can specify which |
| One-time use | Keep for later |
