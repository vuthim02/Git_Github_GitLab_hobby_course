
### Key Insights

1. **Branches are pointers** - Not copies of files
2. **HEAD is location** - Where you are right now
3. **Merging combines** - Changes from different lines
4. **Conflicts need help** - Git can't decide automatically
5. **Workflows bring order** - Structure to development
