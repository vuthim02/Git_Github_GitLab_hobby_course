# Day 14 Exercises: Week 2 Review

## Challenge 1: Recreate All Concepts

Demonstrate mastery by creating:
1. Multiple branches
2. Switches between them
3. Commits on each
4. Merge scenarios
5. Conflict and resolution

## Challenge 2: GitFlow Implementation

Create a complete GitFlow structure:
```
main ──────────────────── [v1.0] [v1.1]
  ↑   ↗                  ↑      ↗
develop ─────────────── [dev] [dev]
  ↑   ↗   ↗                 ↗
feat-a  feat-b          release
```

## Challenge 3: Workflow Design

Design a branching strategy for:
- 3 developers
- Weekly sprints
- Monthly releases
- Emergency hotfixes

Document:
- Branch types
- Naming convention
- Merge strategy
- Release process

## Challenge 4: Problem Solving

Given this scenario:
```
A → B → C → D → F (main)
        ↓
        E → G (feature)
```

What happened here? How would you resolve if needed?

## Challenge 5: Speed Test

Time yourself completing:
1. Create repo with commit
2. Create 3 feature branches
3. Add commits to each
4. Merge all into main
5. Visualize history

Target: Under 5 minutes
