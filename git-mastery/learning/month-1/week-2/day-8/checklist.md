## Post-Lesson Checklist

- [ ] Completed all exercises

- [ ] Verified understanding with `git branch` output

## Quick Reference

```bash
git branch           # List branches
git branch <name>    # Create branch
git branch -v        # List with details
git branch -a        # List all (local + remote)
```

## Success Criteria

You are ready for Day 9 when you can:
1. Create a branch without switching to it
2. List all branches in a repository
3. Identify which branch you're currently on
4. Explain what a branch represents in Git
