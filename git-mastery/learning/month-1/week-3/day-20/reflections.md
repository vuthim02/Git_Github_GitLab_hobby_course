# Day 20 Reflections: GitLab & Merge Requests

## What I Learned Today

### GitHub vs GitLab

| Feature | GitHub | GitLab |
|---------|--------|--------|
| Terminology | Pull Request | Merge Request |
| CI/CD | GitHub Actions | Built-in CI |
| Forks | Yes | Yes |
| Self-hosted | Enterprise | Community Edition |

### Merge Request Process

Same as Pull Request:
1. Create branch
2. Push changes
3. Create MR
4. Review
5. Merge

### GitLab Extras

- **Built-in CI/CD**: No separate service needed
- **Container Registry**: Docker image storage
- **Package Registry**: Language packages
- **Advanced DevOps**: More integrated tools
