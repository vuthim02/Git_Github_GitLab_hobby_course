# Day 16 Checklist: Cloning & Fetching

## Clone Commands

- [ ] `git clone <url>` - Clone to current directory
- [ ] `git clone <url> <folder>` - Clone to specific folder
- [ ] `git clone --depth 1 <url>` - Shallow clone

## Fetch Commands

- [ ] `git fetch <remote>` - Fetch from specific remote
- [ ] `git fetch --all` - Fetch from all remotes
- [ ] `git fetch origin <branch>` - Fetch specific branch

## Verification

- [ ] `git remote -v` - Verify remote configured
- [ ] `git branch -r` - List remote-tracking branches
- [ ] `git log origin/main` - View remote main

## Understanding Remote-tracking

Remote-tracking branches:
- [ ] Named as `<remote>/<branch>`
- [ ] Read-only copies
- [ ] Updated by fetch
- [ ] Cannot checkout directly (usually)
